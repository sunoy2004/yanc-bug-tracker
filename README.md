# Yanc Bug Tracker

This is a Vite + React + TypeScript project (shadcn-ui + Tailwind CSS).

Local development

1. Install dependencies:

```sh
npm install
```

2. Start dev server:

```sh
npm run dev
```

Open http://localhost:5173 (or the port shown in the terminal).

Technologies
- Vite
- TypeScript
- React
- Tailwind CSS

Deployment

Build for production:

```sh
npm run build
```

Then serve the `dist` folder with your preferred static host.
